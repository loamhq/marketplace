# Word count

A quiet count of the words in the message you are writing, shown beside the
send button. Useful when you are keeping a prompt short, or writing a note to
a length.

- Counts as you type, in your browser.
- Sends nothing anywhere, stores nothing, and reads only the text in the
  composer while it is open.
- Turn it off in Settings › Plugins and the count goes away.

## How it counts

Words are runs of letters, digits or apostrophes, in any script, so "don't"
is one word and "東京" is one. Markdown symbols are not words.
