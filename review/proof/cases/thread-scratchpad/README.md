# Thread scratchpad

Keep a small Markdown scratchpad beside each conversation.

Press **Scratchpad** in any thread's header to read or update that thread's
scratchpad file. Changes are saved to your Loam through its built-in
`thread.file` contribution with revision checks so conflicting edits are not
silently overwritten.

- Runs only in your browser; no server code and no external network requests.
- Requires Loam 0.2.28 or later.
